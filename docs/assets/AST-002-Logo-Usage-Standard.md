# Logo Usage Standard

---

# Executive Summary

This standard defines how enterprise logos shall be displayed, resized, positioned and protected across all ForgeOS products, services and communication channels.

Consistent logo usage strengthens brand recognition, preserves visual identity and prevents misuse.

---

# Purpose

This standard aims to:

- Ensure consistent logo usage
- Protect brand identity
- Standardize logo placement
- Prevent visual distortion
- Support accessibility
- Improve cross-platform consistency

---

# Scope

Applies to all official enterprise logos including:

- Primary Logo
- Secondary Logo
- Symbol / Logomark
- Partner Lockups
- Product Logos
- Event Logos
- Application Icons
- Favicons

---

# Logo Variants

## Primary Logo

Default logo used in most situations.

Preferred usage:

- Websites
- Documentation
- Applications
- Marketing

---

## Secondary Logo

Used when layout constraints prevent the primary logo.

---

## Symbol

Used when space is limited.

Examples:

- Mobile App Icon
- Browser Favicon
- Social Avatar

---

## Monochrome Logo

Used when color printing or single-color production is required.

---

# Minimum Size

Minimum recommended sizes:

| Asset | Minimum Size |
|---------|--------------|
| Print | 20 mm |
| Web | 120 px |
| Mobile Icon | 48 px |
| Favicon | 32 px |

Logos shall remain fully legible at all sizes.

---

# Clear Space

A minimum clear space shall surround every logo.

Recommended rule:

```text
Minimum clear space = Height of the logo symbol
```

No text, graphics or interface elements shall enter this area.

---

# Approved Backgrounds

Logos may be placed on:

- White
- Brand Primary
- Brand Secondary
- Approved Neutral Colors
- High-contrast photography

Backgrounds shall provide sufficient visual contrast.

---

# Color Variants

Approved versions include:

- Full Color
- Black
- White
- Monochrome

No other color variations are permitted unless approved by the Brand Office.

---

# Alignment

Recommended alignment:

- Top Left
- Center
- Bottom Left

Positioning shall remain consistent across similar layouts.

---

# Incorrect Usage

The following modifications are prohibited:

- Stretching
- Compressing
- Rotating
- Recoloring
- Applying gradients
- Applying shadows
- Changing proportions
- Adding outlines
- Cropping
- Recreating the logo

Only approved source files may be used.

---

# Accessibility

Logo usage shall support accessibility by ensuring:

- Adequate color contrast
- Sufficient size
- Proper spacing
- High-resolution rendering
- Alternative text in digital products

---

# Digital Usage

For digital products:

- Use SVG whenever possible.
- Optimize PNG assets for legacy environments.
- Avoid bitmap scaling.
- Support dark mode where applicable.

---

# Print Usage

For printed materials:

- Use vector formats.
- Preserve CMYK color definitions.
- Maintain minimum print size.
- Avoid rasterized logos.

---

# File Naming Convention

Recommended format:

```text
brand-logo-variant-version.extension
```

Examples:

```text
forgeos-logo-primary-v1.svg

forgeos-logo-white-v2.svg

forgeos-symbol-v1.png
```

---

# Asset Distribution

Official logo assets shall be distributed exclusively through the enterprise asset repository.

Repositories shall maintain:

- Version History
- Download Tracking
- Metadata
- Preview
- Access Control

---

# AI Integration

AI may assist with:

- Brand compliance validation
- Logo misuse detection
- Asset classification
- Metadata generation
- Accessibility review

AI shall not generate replacement logos for production use without human approval.

- Use approved artwork

- Preserve proportions
- Follow accessibility guidance
- Support brand consistency
- Undergo formal approval before publication
